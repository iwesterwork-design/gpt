# AgroGuide Android — HC-05

Android-застосунок для підключення GPS-приймача через Bluetooth Classic SPP (HC-05) і показу AgroGuide у вбудованому WebView.

## Збірка APK

Проєкт збирається через GitHub Actions: відкрий вкладку Actions, вибери Build AgroGuide APK та натисни Run workflow. Після завершення завантаж артефакт AgroGuide-debug-apk.
